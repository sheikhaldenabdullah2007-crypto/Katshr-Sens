# Katshr Sensitivity — النسخة المصلّحة

## الملفات
- `index.html`, `style.css`, `main.js` — الواجهة
- `catalog.js` — قائمة الأجهزة المحلية (مختصرة، ليست شاملة)
- `engine.js` — منطق الحساب والتحقق (مشترك بين المتصفح والسيرفر)
- `api/analyze.js` — دالة السيرفر: تبحث بالإنترنت عن مواصفات الهاتف ثم تقترح الحساسية

## التشغيل بدون ذكاء اصطناعي
افتح الموقع عبر أي استضافة ثابتة. سيعمل بالوضع المحلي (تقدير بدون بحث مباشر).

## تفعيل الذكاء الاصطناعي (Vercel)
1. ارفع المجلد كاملًا إلى مشروع Vercel.
2. أضف متغير البيئة `ANTHROPIC_API_KEY` (من console.anthropic.com).
3. اختياري: `ANTHROPIC_MODEL` (الافتراضي `claude-sonnet-5-5`) و`ALLOWED_ORIGIN` إذا كانت الواجهة على نطاق مختلف.
4. أعد النشر. ستتحول الشارة في الصفحة إلى «الذكاء الاصطناعي مفعّل».

المفتاح يبقى على السيرفر ولا يصل للمتصفح. كل طلب بحث يكلّف رصيدًا (بحث ويب + توليد)، وفي الدالة تحديد معدل بسيط (10 طلبات/10 دقائق لكل IP) لكنه best-effort فقط في بيئة serverless؛ للإنتاج استخدم تحديد معدل حقيقي (مثل Upstash أو Vercel Firewall).
