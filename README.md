# Katshr Sensitivity — محرك حساسية Free Fire (مقياس 0–200)

## كيف يعمل (وضع الذكاء الاصطناعي)
عند اختيار الهاتف يشغّل السيرفر بحثًا متعدد المراحل:
1. آخر تحديث للعبة: النسخة (OBxx) وتاريخها وما تغيّر ويخص التصويب/الإعدادات.
2. مواصفات الجهاز الحقيقية: المعالج، الذاكرة، معدل التحديث.
3. أدلة الإعدادات لهذه النسخة (مقياس 0–200 فقط، تُستبعد أدلة 0–100 القديمة).
4. اشتقاق القيم من الأدلة مع شرح "basis" وروابط المصادر.

الصرامة: إذا نقصت قيمة، أو خرجت عن 0–200، أو كان ترتيب المناظير غير منطقي، أو وُجد أقل من مصدرين صالحين، تُرفض النتيجة ويظهر ذلك للمستخدم بدل عرض أرقام مخمّنة. الروابط تُقبل فقط إذا ظهرت فعليًا في نتائج البحث.

## بدون ذكاء اصطناعي
يعمل الموقع بوضع محلي معنوَن «تقدير محلي»: قيم من أدلة 2026 المنشورة + تعديل حسب فئة الجهاز، بدون بحث مباشر.

## النشر (Vercel)
1. ارفع المجلد كاملًا.
2. أضف `ANTHROPIC_API_KEY` في Environment Variables. اختياري: `ANTHROPIC_MODEL` (الافتراضي `claude-sonnet-5-5`) و`ALLOWED_ORIGIN`.
3. `vercel.json` يضبط مهلة الدالة 120 ثانية؛ قد تحتاج خطة تدعم ذلك. البحث الكامل يستغرق عادة من نصف دقيقة إلى دقيقتين.
4. كل طلب يستهلك رصيدًا (حتى 8 عمليات بحث + توليد). تحديد المعدل المضمّن (10 طلبات/10 دقائق لكل IP) بسيط فقط؛ للإنتاج استخدم تحديد معدل حقيقي.

## ملفات
`index.html, style.css, main.js` الواجهة · `catalog.js` أجهزة محلية مختصرة (غير متحقق منها آنيًا) · `engine.js` منطق مشترك · `api/analyze.js` دالة البحث.
